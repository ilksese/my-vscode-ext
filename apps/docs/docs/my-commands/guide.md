# 使用指南

## 侧边栏管理命令

1. 点击侧边栏的 **my-commands** 图标打开管理面板。
2. 点击 **新建命令** 输入命令名称与执行内容。
3. 保存后命令立即生效，可随时编辑或删除。

每个命令可以配置：

- **名称**：在面板与菜单中显示的名称。
- **执行内容**：实际运行的 shell 命令，支持变量占位符。
- **是否在右键菜单出现**：决定该命令是否出现在编辑器右键菜单。

## 从右键菜单运行

在编辑器打开一个文件，点击右键，`my-commands` 命令分组下列出已启用的命令。

点击后会针对 **当前活动文件** 执行，支持通过占位符引用文件路径。

## 查看输出

命令执行过程与结果输出到 VSCode 的 Output Channel（视图 → 输出，选择 `my-commands`）。

## 超时与取消

命令默认 **30 秒** 超时。超时或执行中可手动取消，避免阻塞。

## 示例

| 命令名 | 内容 | 说明 |
| ------ | ---- | ---- |
| 格式化 JSON | `npx jsonlint ${file} ` | 校验当前文件 |
| 打开目录 | `open ${fileDirname}` | 在访达中打开当前目录 |

> 占位符详情见 [变量替换](./variables)。
