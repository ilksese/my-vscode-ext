# my-commands

⚙️ 自定义命令执行工具，通过侧边栏管理与编辑器右键快速运行自定义命令。

## 特性

- **侧边栏管理**：增删改查自定义命令，实时生效。
- **右键运行**：在活动文件上点击右键即可执行针对该文件的命令。
- **变量替换**：内置 7 种占位符，支持 `${file}`、`${workspaceFolder}` 等。
- **实时输出**：命令执行结果输出至 VSCode Output Channel。
- **安全转义**：所有命令经 ShellAdapter 跨平台转义（Windows/macOS/Linux）。
- **超时取消**：默认 30 秒超时，支持手动取消。

## 快速开始

1. 从 [安装](./installation) 安装插件。
2. 在侧边栏添加第一条命令。
3. 需要了解占位符用法，请阅读 [变量替换](./variables)。
